Version 1.1.1 · Android 7.0 and newer · Signed release

Install in three steps

  1. Download the APK, then open it from your phone’s Downloads folder.
  2. If Android asks, allow installation from your browser or file manager. On Android 7, this setting is usually under Settings → Security → Unknown sources. Turn it off again after installation.
  3. Tap Install, open Cartlyft, and sign in with your existing account while connected to the internet.

Your business data uses the same account and database. You will sign in again in the app; browser sessions do not transfer automatically.

For order alerts, keep the app open. This release supports in-app alerts, but does not receive push notifications while closed. Staff changes saved on the phone sync when internet returns. Customer orders need internet confirmation.

Updating later

Download the newer APK and install it over the existing app. Do not uninstall or clear app storage while changes are waiting to sync.

If the screen won’t load

Enable or update Android System WebView and Google Chrome in the Play Store, then reopen the app. Use the app’s ⋮ menu for Reload, printing, and updates.
